# STRATFUSION — Multi-Source Intelligence Fusion Dashboard

A web-based intelligence dashboard built with Python (Flask) + Leaflet.js

## Features
- OSINT, HUMINT, IMINT data visualization
- Interactive geospatial map with clickable markers
- Drag & drop CSV/JSON/JPG upload
- Threat level filtering
- Hover modals with imagery support

## Setup
pip install -r requirements.txt
python app.py

## Stack
Python · Flask · Leaflet.js · JavaScript · HTML/CSS
